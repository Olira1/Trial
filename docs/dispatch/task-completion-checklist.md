# Dispatch Task Completion Checklist

**Status:** Active

**Type:** Reference

This checklist is the persistent record of what was updated for each completed
Instant Ride dispatch task. Update it before proposing the task commit.

## Required Checklist

For every completed dispatch roadmap task:

- [ ] Record the task ID, task name, completion date, and commit hash or
      pre-commit status.
- [ ] List every production, test, migration, infrastructure, and documentation
      file updated by the task.
- [ ] Mark the roadmap item complete in `docs/dispatch/master-roadmap.md`.
- [ ] Mark the phase playbook task complete in the active phase file.
- [ ] Update `docs/dispatch/current-status.md` with the latest completed task,
      verification commands, and next task candidate.
- [ ] Add accepted decisions to `docs/dispatch/decision-register.md`.
- [ ] Add or update risks in `docs/dispatch/risk-register.md`.
- [ ] Add or resolve existing-system findings in
      `docs/dispatch/existing-system-findings.md` when relevant.
- [ ] Update task-specific reference docs such as testing, spatial, API/event,
      deployment, or operations docs when behavior or rules changed.
- [ ] Record the focused tests, typecheck, lint, build, and full-suite results.
- [ ] Note transaction/concurrency, security/authorization, and operational
      review outcomes in the final task report.
- [ ] Confirm unrelated user files were left unstaged.
- [ ] Propose a small Conventional Commit message and wait for explicit approval.
